# Cloudinary Upload Prep Evidence

This folder preserves the small, human-readable evidence subset copied from the local generated workspace at `exports/tpp-cloudinary-upload-prep/`.

Only Markdown reports and the Markdown upload-prep review sheet are committed here. The generated export workspace also contains bulk image folders, upload command wrappers, JSON/CSV manifests, local HTML galleries, and binary contact sheets; those remain local unless a future task deliberately selects a smaller reviewed subset.

The bulk generated media still lives locally under `exports/`, including upload-ready folders and review buckets. Those generated exports should not be committed wholesale because they are large local workspace output, not source material for the repo.

Some copied Markdown files include relative image links from their original export context. The links are preserved as evidence of the generated review output; the image files themselves were intentionally not copied into docs.
